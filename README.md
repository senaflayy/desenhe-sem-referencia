desenhe-sem-referencia

Jogo multiplayer para Roblox em que dois jogadores recebem o mesmo tema e desenham sem referência. No fim, os dois desenhos aparecem lado a lado.

Jogue aqui: [Desenhe Sem Referência | Jogue na Roblox](https://www.roblox.com/pt/games/103642134910160/Desenhe-Sem-Refer-ncia#!/about)

Como funciona

1. Dois jogadores sentam nas cadeiras de uma mesma dupla.
2. O jogo sorteia um tema aleatório, igual para os dois.
3. Cada um desenha numa folha em branco, com paleta de cores, pincéis de tamanhos diferentes e borracha.
4. Quando os dois enviam, a tela de revelação mostra os desenhos lado a lado.
5. A rodada reinicia com um novo tema.
